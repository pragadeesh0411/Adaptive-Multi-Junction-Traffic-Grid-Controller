TECHNICAL PROJECT REPORT

AMTGC – Adaptive Multi-Junction Traffic Grid Controller

1. Project Overview

AMTGC is a Verilog HDL-based digital traffic-control system for two coordinated four-way junctions. It combines adaptive traffic-density control, fair pedestrian arbitration, emergency override and green-wave coordination.

2. Architecture

The system contains Junction A and Junction B controllers, a reusable generic timer, a shared pedestrian arbiter and a green-wave coordinator. The top-level module amtgc_top integrates these blocks using named port connections.

3. RTL Design

The RTL is modular and parameterized. The generic timer provides reusable timing, while the junction controller implements traffic sequencing and adaptive target calculation. Pedestrian arbitration and green-wave synchronization are separated into dedicated modules.

4. FSM Design

The junction controller uses seven Moore FSM states: NS Green, NS Yellow, All-Red to EW, EW Green, EW Yellow, All-Red to NS and Pedestrian. Explicit all-red phases provide a safety interval between conflicting directions.

5. Adaptive Traffic-Density Control

A 3-bit density input provides levels 0 through 7. The controller computes a green target from a base green time and a per-level extension, then clamps the target to configured minimum and maximum limits. Density is sampled at green-phase entry so an active green phase is not continuously retimed.

6. Verification Methodology

Verification uses a self-checking ModelSim testbench with directed scenarios, corner cases and randomized activity. The environment checks valid FSM states, conflicting-green safety, emergency handling, pedestrian grant behavior, adaptive timing, reset and green-wave coordination.

8. Challenges Faced

Key challenges included maintaining a strict top-level hierarchy, handling fair pedestrian arbitration, coordinating green-wave timing, isolating adaptive logic from the generic timer, and diagnosing compile/elaboration and waveform issues during integration.

9. Conclusion

AMTGC demonstrates a practical modular RTL architecture for coordinated traffic control. The design combines deterministic FSM sequencing with adaptive timing, fair pedestrian service, emergency safety handling and inter-junction coordination.

10. Future Enhancements

Possible extensions include real-time vehicle sensors, camera-based density estimation, FPGA hardware deployment, additional coordinated junctions, emergency vehicle detection and predictive traffic optimization.
