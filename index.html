AMTGC

Adaptive Multi-Junction Traffic Grid Controller

Verilog HDL | ModelSim | RTL Design | Digital Systems

Project Overview

AMTGC is a Verilog HDL based digital traffic-control system designed to coordinate two four-way traffic junctions. The system integrates adaptive traffic-density control, pedestrian arbitration, emergency override and green-wave coordination.

Key Features

Adaptive Traffic Control

Green duration is dynamically adjusted according to traffic-density input.

Pedestrian Arbitration

Shared and fair pedestrian request handling between Junction A and Junction B.

Emergency Override

Provides a safe all-red condition during emergency operation.

Green-Wave Coordination

Coordinates North-South traffic between the two junctions.

Moore FSM

Traffic sequencing is implemented using a finite-state machine.

Self-Checking Verification

The complete system is verified using ModelSim and a self-checking testbench.

Technology Used

Verilog HDL, ModelSim, Intel FPGA development environment, finite-state machines, parameterized RTL and simulation-based verification.
